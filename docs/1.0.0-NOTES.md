# Eigen Launcher 1.0.0

The first release of Eigen, the launcher that grew out of the 72F Launcher betas and RCs. It is a new app (`com.studio72f.eigen`, version code 1), so it installs beside the 72F builds rather than over them.

## What's new since 72F RC6

- **A new home, on Compose and Kelvin.** Drawers that open in place, pull down to open them all, an A–Z app drawer on a swipe up, a four-app dock, and search that hands questions to the assistant. The category rail, the XMB look and the Retro, Wave and Expressive themes are retired.
- **Side pages.** Conversations and the Assistant on the left, the widgets page on the right.
- **Eigen's own widgets**, stacked from the bottom: hold to reorder or remove. App widgets sit beside them, edge to edge.
- **An on-device assistant**: Gemini Nano through AICore, or quick answers where there is no model.
- **App dashboards**: time today hour by hour, storage, and the card's style on home.
- **Frost**, Kelvin's deep ground glass, as the default look, with Liquid glass as the alternative; shader textures as wallpapers.
- **Eigen Plus**, a one-time unlock. See below.

## Eigen Plus

Free Eigen is the whole launcher. Plus adds:

- unlimited contexts (free: everyday plus one);
- three more clocks;
- every texture;
- Stained, Lit and wide cards;
- five more widgets;
- Conversations.

Plus clocks and card styles can be tried on. Gates sit where things are chosen, never on what's already set up. Any install from before Plus keeps it for good. Plus is a non-consumable Play product, checked against Play's on-device purchase record; tips stay separate and unlock nothing.

## Privacy

The internet permission that ML Kit's telemetry library adds is removed in the manifest, so Eigen again requests no internet permission. The assistant runs in AICore on the phone, and billing goes through the Play Store app.

## Verification

All on the Android 17 emulator (Medium Phone, API 37).

- **JVM tests:** 37.
- **On-device engine checks:** 117. Updated for the retired XMB layout; new: Plus survives a backup restore.
- **`eigen-smoke.py`:** 23 checks, passing on both the debug and the R8 `qa` build. It replaces the six 72F UI suites, which drove the old category UI under a package name the app no longer has.
- **Lint:** no issues. Gradle 9.8.2, core-ktx 1.19.1; ML Kit GenAI held at beta2 until it can be tested on an AICore phone.
- **Release APK:** 4.9 MB, R8 and resource shrinking.

## Before shipping

- **Production key.** Run `scripts/make-release-key.sh` to create it, then `scripts/release.sh` to sign with it. The first key used on Play is permanent.
- **Play Console.** Create `eigen_plus` as a one-time product. Then test a purchase, a refund and a restore with a licence-test account; billing could not be exercised on the emulator.
- **Real phones.** Test on physical devices, including Android 9–16, OEM gesture navigation, TalkBack, live media sessions, headphones and Smartspacer.
